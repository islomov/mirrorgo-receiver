# Skills

The SEO skills here are copied from [islomov/skills](https://github.com/islomov/skills) `web/` at `a6c236b`
(PR #13, MIRR-189). Change them there and copy them back.

| Skill | Use it for on alltvkit.app (`site/`) |
|---|---|
| `seo-roast` | What blocks crawling, indexing or App Store taps; fix in a PR, the rest in a roadmap |
| `seo-autopilot` | A recurring SEO run with state in `seo/` |
| `seo-title-optimization` | Titles, H1s and descriptions (in `content.py`, `blog.py`, `locales/`) |
| `blog-refresher`, `unslop-seo` | Improving the blog's how-tos |
| `internal-linking` | Links between posts and the home page. Its script only reads Next.js / Astro / MDX sources, so run it on `site/public/` or adapt `routeOf()` |
| `vs-and-alternatives` | Comparison pages against other casting / mirroring apps |
| `seo-blog-images` | Covers and screenshots for posts |
| `domain-migration` | mirrorgo.app → alltvkit.app |
| `seo-skills-upstream` | The 21 upstream skills not copied, and how to bring one in |
